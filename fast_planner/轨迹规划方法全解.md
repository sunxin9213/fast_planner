# 移动机器人轨迹规划方法全景梳理（学习笔记）

> 本文档系统性梳理移动机器人/无人机/足式机器人路径与轨迹规划的常用开源与经典方法，分为**前端（全局规划）**与**后端（局部规划 / 轨迹优化）**两部分，覆盖原理、流程、优缺点与典型开源项目，便于对照学习。
>
> 核心思想总纲：**"前端找形，后端成形"**。
> - **前端（全局规划 / Global Planning）**：在地图/图结构上找一条从起点到目标点的（通常几何上）可行路径，输出离散路径点序列（不保证动力学可行）。
> - **后端（局部规划 / 轨迹优化 / Trajectory Optimization）**：把前端路径（或其参考）变换/优化成一条平滑、安全、满足动力学约束的**带时间信息的轨迹**。

---

# 第一部分：前端（全局规划）方法

## 0. 前端方法分类框架

```
前端全局规划
├── 基于图的搜索（Graph Search）
│   ├── 确定性完备：Dijkstra, A*, JPS
│   ├── 动态/增量：D\*, D\* Lite, LPA*, Field D*
│   ├── 含代价地图启发：Theta*, ARA*（any-angle, 次优）
│   └── 融入动力学：Hybrid A*, Kinodynamic A*
├── 基于采样的规划（Sampling-based）
│   ├── 路线图：PRM, Lazy PRM, PRM*, S-PRM
│   ├── 增量树：RRT, RRT*, RRT-Connect, Informed RRT*, Kinodynamic RRT*
│   └── 势场类：Artificial Potential Field (APF)（可视为连续采样）
└── 基于栅格代价/搜索：Dijkstra, Wavefront（BFS），跳点搜索 JPS
```

## 1. 基于图的搜索算法

### 1.1 Dijkstra（迪杰斯特拉）
**原理**：单源最短路径算法，基于贪心 + 无负权边。以起点为中心，用优先队列不断扩展"当前代价最小"的节点，直到目标出队。

**流程**：
1. 起点 `g=0` 入开放集。
2. 弹出 `g` 最小的节点 `n`。
3. 遍历 `n` 的邻接节点 `m`，若 `g(n)+cost(n,m) < g(m)` 则更新 `g(m)` 并记录父指针。
4. 重复直到目标节点出队。

**特点**：
- **完备且最优**（在图上）。
- 无启发式引导，搜索范围大，效率低。

### 1.2 A*（A-Star）
**原理**：在 Dijkstra 基础上引入启发式 `h(n)`（到目标代价的下界估计），用评价函数：
```
f(n) = g(n) + h(n)
```
只要 `h` 满足**可采纳性（admissible，不高于真实代价）**与一致性，A* 仍保证最优，但搜索节点远少于 Dijkstra。

**流程**：
1. 起点入开放集 `f=0+h(start)`。
2. 弹出 `f` 最小节点。
3. 扩展邻域，更新 `g`、`h`、记录父指针。
4. 直到目标被选中或开放集为空。

**变体**：
- **Weighted A\***：给 `h` 加权 `f=g+w·h`，牺牲最优性换速度，可配合 ARA* 做增量降权逼近最优。
- **Anytime A\***（ARA*）：运行期间不断返回当前次优解，随可用时间收紧权重提升质量。

### 1.3 Dijkstra / A* 的栅格实现 `?`
在栅格地图上，节点的邻接关系由连通性定义（4 邻域 / 8 邻域 / 或多层），代价可基于 `clearance`（到障碍距离）或地形代价生成**代价地图**来驱动。

### 1.4 Jump Point Search（JPS，跳点搜索）
**原理**：针对**均匀代价的栅格**空间，利用"对称路径"大量冗余的特性，通过**剪枝规则**直接"跳跃"到关键拐点（Jump Point），避免逐个扩展平坦区域节点。

**适用**：2D 栅格、8 邻域、均匀代价。**注意**：它是 A* 的加速技巧，不适合非均匀代价图 / 3D 复杂动态。

### 1.5 D*（Dynamic A*）
**原理**：动态稀疏 A*，针对**部分未知地图**。首次按 A* 从目标向前搜索并估代价，当发现新障碍（地图更新）时，**只修复受影响区域的路径**（将受影响节点重新入开放集），大幅减少重规划开销。适用于 Robot Operating System 中的老式探索导航。

### 1.6 D* Lite
**原理**：D* 的改进版，逻辑上按"从目标反向往起点搜索"，复用了 LPA*（Lifelong Planning A*）的增量思想。当环境变化时同样**局部更新**，实现高效重规划。**实际工程中 D* Lite 比 D* 更常用**（代码更清晰、后续维护更好）。

**流程**：
1. 从目标开始反向传播，初始化所有节点 `g=∞`、`rhs=∞`。
2. 用 `min(g,rhs)` 与 key 决定扩展顺序（类似 A* 的 `f`）。
3. 路径变化 → 受影响节点更新 `rhs` → 重新入优先队列。
4. 不断沿当前节点走向目标，期间若发现子图代价变化则增量修复。

### 1.7 Theta* / Field D*
**原理**：**任意角度（Any-Angle）**路径规划，允许路径以任意角度通过网格，消除 A* 的 45° 折线痕迹。Theta* 在扩展时检查子节点是否与**祖父节点**直接可见，可见则缩短路径（绕过中间网格点）。Field D* 用插值在网格边之间生成更平滑、代价更低的任意角度路径。

**特点**：更适合无人机等对路径平滑度敏感的场景（但仍需后端优化）。

### 1.8 Hybrid A*（混合 A*）
**原理**：针对带**非完整动力学约束**（如车辆最小转弯半径，不能原地转向）的机器/无人机。在连续姿态空间（`x,y,θ`）上用 A* 搜索，节点状态由运动模型推进，配合**向前看（look-ahead）**和碰撞检测。常用于自动驾驶泊车、自主代客泊车（典型开源：`nav2` 的 Smac Planner-Hybrid-A*）。

**流程**：
1. 状态离散化到网格（姿态格），但网格内状态连续。
2. 用转向/加速命令推进运动学模型，扩展多个候选状态。
3. 结合 Reeds-Shepp 曲线等作终点连接求解。
4. 后端再用样条/曲线平滑。

## 2. 基于采样的规划算法

面向**高维、连续、非凸**空间，避免对状态空间做显式离散化。优点是**概率完备**（样本无穷多时一定找到可行解），缺点是可能非最优（除 RRT* 等最优变体）。

### 2.1 PRM（Probabilistic Roadmap，概率路线图）
**原理**：构建一张**路线图（roadmap）**，节点为随机采样得到的碰撞检测通过的构型，若两节点间直线连接可行则连边。查询阶段用 Dijkstra/A* 在图里搜索最短路径。

**流程（两阶段）**：
1. **学习阶段**：在地图上均匀随机采样 N 个点 → 过滤掉碰撞点 → 对每个点尝试与其邻域内若干点连线（检碰撞）→ 得到图 `G`。
2. **查询阶段**：把起点、终点也接入 `G`，用图搜索求最短路径。

**特点**：
- **多查询**：建图一次，可反复查询多条起止对，适合静态环境。
- **缺点**：建图成本高；对"窄通道（narrow passage）"采样命中率低。

**变体**：
- **Lazy PRM**：先不检碰撞只建潜在边，查询得到候选解后再渐进检碰撞，节省大量碰撞检测。
- **PRM\***：渐近最优的 PRM 变体，边连接半径随节点数按 `r = γ(log n/n)^{1/d}` 收缩，样本足够时收敛到最优。

### 2.2 RRT（Rapidly-exploring Random Tree，快速扩展随机树）
**原理**：从起点生长一棵树，每次随机采样一个目标点，沿树中最近节点向采样点步进扩展，直到触及目标。天然适合高维、带约束空间。

**流程**：
1. 树初始化只含起点。
2. 随机采样 `x_rand`（有时偏置向目标以加速）。
3. 在树中找距 `x_rand` 最近的节点 `x_near`。
4. 在 `x_near → x_rand` 方向以步长 `δ` 推进得到 `x_new`，检碰撞。
5. 无碰撞则把 `x_new` 加入树。
6. 重复直到 `x_new` 接近目标，或达到最大迭代数。

**特点**：
- **增速快、概率完备**，适合高维与复杂约束。
- **非最优**，路径曲折。

### 2.3 RRT*（最优 RRT）
**原理**：在 RRT 基础上增加**重连线（rewire）**步骤，不断用更优父节点替换，使树在样本足够时**渐近最优**（收敛到最短路径）。

**流程**（在 RRT 步骤上加两步）：
1. 找到 `x_new` 的邻域候选父节点集合。
2. **ChooseParent**：选代价最小者作父节点。
3. **Rewire**：检查能否用 `x_new` 作为邻域内其他节点的父节点以降低代价，能则重连线。

**变体**：**Informed RRT\***（只在高概率区域采样，加速收敛）、**RRT-Connect**（双向树，从起终点同时生长，速度快，常用于运动规划如 MoveIt）。

### 2.4 Kinodynamic RRT* / Kinodynamic RRT
**原理**：把 RRT/RRT* 的构型空间扩展为**状态空间（位置+速度等）**，节点间以符合动力学约束的轨迹段（而非直线）连接。用于无人机、机械臂等有动力学约束的机器人。Fast-Planner 的 `Kinodynamic A*` 本质是把这一思路放回图搜索（可裁剪成带状探索，见后）。

### 2.5 人工势场法 APF（Artificial Potential Field）
**原理**：把目标设为引力场、障碍设为斥力场，机器人沿合力方向移动。

**流程**：
1. 计算势场函数 `U = U_att + U_rep`。
2. 取负梯度得合力 `F = -∇U`。
3. 沿 `F` 方向步进，循环到达目标。

**特点**：实时性好、连续平滑，但**容易陷入局部极小**、目标不可达（GNRON）。常用于局部避障而非完整前端。

## 3. 融入动力学约束的前端（Fast-Planner 风格）

### 3.1 Kinodynamic A*（动力学 A*）
**原理**：在 A* 框架下，状态为**连续运动状态**（位置 + 速度 = 6 维，无人机常取位置/速度/加速度），节点间以**常加速度 / 动力学模型积分**扩展出轨迹段。启发函数用动力学感知的耗时/代价估计，可在终止条件附近用"shooting"多项式直接收敛。

**流程**（Fast-Planner 实测）：
1. 起点状态（位置/速度/加速度）入堆。
2. 弹出 `f = g + h` 最小者；`h` 用动力学启发式（恒定加速度到目标的最小代价）。
3. 采样多组**加速度方向控制输入**，用四元数/双积分推进一个固定时长求末端状态。
4. 末端状态经过碰撞检测（ESDF），计算 `g` 后入堆。
5. 扩展节点足够接近目标时，尝试 **computeShotTraj()** 直接多项式连接；全程无碰撞则收敛。
6. 返回离散状态序列，供后端 B 样条拟合。

**价值**：前端直接给出"动力学可行、时间可估计"的路径，后端无需处理动力学不可行问题，只专注平滑与避障。

### 3.2 核心工具：距离场（ESDF / FMM）
Fast-Planner 前端与后端会反复查询**欧氏带符号距离场（ESDF）**，`F(x)>0` 表示到最近障碍的距离，用于：
- 前端：快速碰撞检测；
- 后端：把"离障碍近"转化为可微的代价惩罚。

# 第二部分：后端（局部规划 / 轨迹优化）方法

后端输入：前端路径（离散点集）或参考轨迹；输出：**满足平滑、安全、动力学限制、且带时间参数**的轨迹。

```
后端局部规划 / 轨迹优化
├── 时间离散 / 采样类（reactive）
│   ├── DWA 动态窗口法
│   └── VFH 向量场直方图（可在局部）
├── 导航/局部优化类
│   └── TEB 时间弹性带
├── 轨迹生成类（多项式）
│   ├── Minimum Snap / Minimum Jerk（多项式最小化）
│   ├── Bezier 曲线
│   └── MINCO（Minimum Control）
├── 曲线 / 样条类
│   ├── B-Spline（含非均匀 B 样条，Fast-Planner）
│   ├── 三次样条 / 切向量样条（Cubic / Catmull-Rom）
│   └── 均匀 B 样条快速可行性检查
└── 最优控制 / MPC 类
    ├── 离散 MPC
    ├── 模型预测路径积分（MPPI）
    └── 非线性 MPC（足式、无人机竞速）
```

## 1. DWA（Dynamic Window Approach，动态窗口法）

**原理**：在**速度空间上采样**，把动力学约束转化为"可达速度窗口"——仅考虑机器人**当前可达的**速度组合（线速度 `v` + 角速度 `ω`），对这些候选速度逐一模拟短时轨迹。

**流程**：
1. 构造动态窗口：由 `[v_min,v_max] × [ω_min,ω_max]`，再以加速度限制收缩为当前可达窗口。
2. 在窗口内采样若干 `(v,ω)`。
3. 对每个采样速度，向前模拟一小段圆弧/轨迹。
4. 用评价函数：`score = α·heading(指向目标) + β·clearance(离障碍远) + γ·velocity(速度快)`。
5. 选总分最高者作为本周期期望速度。

**特点**：计算快、实现简单，适合移动底盘；**贪心局部**，易陷入局部极小；是 ROS `dwa_local_planner` 的基础。

**变体**：**DWA 带规划（Trajectory Rollout）**在 ROS1 中常用；nav2 改用更平滑的版本。

## 2. TEB（Timed Elastic Band，时间弹性带）

**原理**：把路径"想象成一条可变形橡皮筋"（弹性带），由一串带时间戳的姿态序列组成。通过求解一个**稀疏非线性最小二乘优化**，在保持"端点固定 + 避障（离障碍远）+ 时间最优 + 运动学/动力学可行"之间折中，让整条带子同时变平滑、安全、省时。

**流程（TEB 局部规划）**：
1. 以前端全局路径为参考，初始化一串位姿 `pose_i` 及其时间差 `Δt_i`。
2. 构造多目标代价：路径长度、与障碍距离、动力学（速度/加速度/转向）约束、时间最小化（`Δt` 尽量小）、与参考路径的贴合度。
3. 通过 **g2o / Ceres** 式稀疏图优化，迭代调整各顶点位姿与时间间隔。
4. 每次更新后去极值点、缩冗余点；以当前机器人位姿为重规划起点，周期执行。

**特点**：**实时重规划能力强**、兼顾时间最优与避障，是移动底盘最流行的局部规划（`teb_local_planner`）。**缺点**：对高速/重动力学（强惯性与非完整约束）建模有限，需合理调参；不是严格保证碰撞避免。

## 3. 多项式轨迹生成（Minimum Snap / Minimum Jerk）

**核心思想（最小化高阶导数）**：把轨迹表示为分段的**多项式**，最小化 `jerk`（加加速度）或 `snap`（急动度的导数，即四阶导数）的能量积分，使轨迹**平滑且过渡自然**。

**Minimum Snap 原理**：
- 对无人机的平动，代价函数：`J = minimize ∫ || p^(4)(t) ||² dt`（snap 的四阶导数积分最小 → 推力变化平缓）。
- 把每段时间多项式的系数作为变量，用**二次规划（QP）**求解，满足各段在**连接点处位置、速度、加速度连续**（航路点约束），并固定起止状态。
- 中间过程常用闭式解（消去等式约束变量）提速，或引入时间分配优化。

**流程**：
1. 把前端路径节点作为航路点，指定每段时间 / 总时长。
2. 构造分段多项式（通常 5 阶 jerk / 7 阶 snap）。
3. 建立连接点连续性等高约束与代价矩阵（Hessian）。
4. 用 QP（如 OSQP、Mosek）求解系数。
5. 采样得到平滑轨迹；如需则再迭代替换航路点或对时间做分配优化。

**特点**：**平滑且可通过解析求梯度**，是无人机轨迹生成的经典方法（R. Gao / Mellinger 等，鲁棒性验证充分）。**缺点**：避障需额外约束（无法直接在代价里表现"避开连续空间障碍"），常配合凸分解或安全走廊（Corridor）。

---

## 4. Bezier（贝塞尔）曲线

**原理**：用控制点定义的参数曲线：`B(t) = Σ Bᵀ(t)·Pᵢ`，其中 `Bᵀ(t)` 是 Bernstein 基函数。**贝塞尔曲线始终位于其控制点凸包之内**（凸包性质），且端点与首末控制点重合。

**特点**：
- **凸包属性**：只要把控制点约束在安全走廊 / 障碍外，曲线必在走廊内 → 天然支持避障约束。
- 基函数为多项式，便于求导、求曲率。
- 全局性：动一个控制点影响整条曲线，曲线阶数随控制点增长。

**流程**：
1. 取前端的若干路径点作为参考，设计控制点初值。
2. 利用凸包性把控制点限制在安全凸多边形/走廊内。
3. 以 Bezier 的高阶导数（对应速度/加速度）构造最小化目标，用 QP 求解控制点。
4. 还原轨迹。

---

## 5. FMM / Fast Marching（快速行进法，可用于后端引导）

**原理**：基于波前传播求解最短路径距离（Eikonal 方程），从目标点向外"按距离增长次序"行进传播，得到到目标的**距离场/代价场**。

**用途**：
- 全局最短路径（可视为一种前端）；
- 作为后端优化的"H 代价指导"或"走廊生成基础"；
- 与 Fast-Planner 的 ESDF 思想相近，但 FMM 是波传播求解。

**流程**：用优先队列按代价递增扩展，更新邻居的到达代价；直到区域被覆盖，得到距离场。

## 6. MINCO（Minimum Control，浙大 FAST Lab）

**原理**：一种**最小控制力轨迹**的统一参数化方法。核心是：**给定轨迹的中间时间节点与控制点，自动产生一条最小"控制输入二阶（或多阶）积分"的轨迹**，且把时间分配也纳入优化变量。

**特点**：
- **参数化+优化解耦**：先用解析式把轨迹表达为控制点的函数，再做无约束/少约束优化，避免大规模硬约束 QP；
- 同时优化**空间（控制点）与时间（时间分配）**，可进一步施加时间最优；
- 广泛应用于 EGO 系列、水下/足式等的通用轨迹类库。

**流程**：
1. 给出航路点与初始时间节点。
2. 用 MINCO 生成最小控制轨迹（控制点 → 轨迹的解析映射）。
3. 构造代价（平滑 + 避障 + 动力学）及其解析梯度。
4. 迭代优化控制点与时间分配，得到最终安全平滑轨迹。

## 7. B-Spline（B 样条）—— Fast-Planner 后端核心

**原理**：由**控制点**与**节点向量（knot vector）**定义的样条，局部支撑（移动一个控制点只影响局部），曲线光滑（p 阶 B 样条具有 p-1 阶连续导数），且满足**强凸包性质**（每段都落在相邻 p+1 个控制点的凸包内）。

**配合 ESDF 的优化（Fast-Planner 实测）**：
- 用控制点做优化变量；
- **平滑度**：最小化加加速度 `||p'''||²`（B 样条的高阶差分得到解析梯度）；
- **安全性**：对靠近障碍的控制点，用 ESDF 的距离惩罚（侵入障碍区域越多代价越大，梯度可由 ESDF 给出）；
- **可行性**：对超出最大速度/加速度的控制点（B 样条的凸包性质保证整段都在限度内）施加惩罚。

**非均匀 B 样条 / 时间调整**：
- 若节点向量取等间距 → **均匀 B 样条**（计算简单）；
- 若不满足物理限制，用 `reallocateTime()` 迭代拉伸节点时间，使速度/加速度回落至限制内；
- `checkFeasibility()` 检查最大速度/加速度是否超标。

**流程**：
1. 把前端路径采样点反算为控制点（`parameterizeToBspline`），保留起止速度/加速度为边界导数；
2. `BsplineOptimizeTraj`：设置 `SMOOTHNESS | DISTANCE | FEASIBILITY`（及可选的 `GUIDE/ENDPOINT`）代价，用 L-BFGS（NLopt）优化控制点；
3. 检查可行性与时间调整，循环迭代使轨迹满足物理限制；
4. 以固定频率用 De Boor 递推 `evaluateDeBoor()` 采样位置/速度/加速度，供控制器跟踪。

**优点**：局部性、解析梯度、整数阶连续可控、实时性好。**缺点**：需有好的初值（通常来自前端搜索）与安全场支撑。

## 8. MPC（Model Predictive Control，模型预测控制）

**原理**：在**有限预测时域**内重复求解一个受动力学约束的**最优控制问题（OCP）**，取第一步控制量作用于系统，窗口滑移、滚动优化。

**特点**：
- **显式处理动力学 + 约束**：速度、加速度、转向、控制输入限制都能作为约束或软代价；
- **实时前瞻**（receding horizon）；
- 成本高：需高效求解器（OSQP、ACADO、NMPC 用 IPOPT / SLQ）。

**分类**：
- **线性 MPC**：模型线性化、LQR 增益形式好解（如俯仰姿态控制）；
- **非线性 MPC（NMPC）**：用于无人机避障竞速、足式步态 MPC（如 ETH ANYmal、MIT Cheetah 质心 MPC）。

**流程**：
1. 建立动力学/运动学模型与目标代价（跟踪参考 + 避障 + 控制量平滑）。
2. 设定预测时域 N 与采样周期 dt。
3. 用数值/非线性求解器求解 OCP，得到 N 步控制序列。
4. 执行第一步，滚动求解。

## 9. MPPI（Model Predictive Path Integral，模型预测路径积分）

**原理**：基于**采样**的最优控制。以当前状态生成大量**带噪声的控制输入采样**，评估每条 rollout 轨迹的代价，用路径积分（指数加权平均）融合出更优控制。

**特点**：
- 无需求解析导数/线性化，可处理**非平滑、非凸、离散**代价（如避障、可通行性）；
- 天然并行（GPU），鲁棒性好；
- 已用于足式机器人、自动驾驶导航。

**流程**：
1. 采样 K 条带噪声控制序列，前向模拟（取当前状态）。
2. 计算各 rollouts 的总代价（跟踪 + 避障 + 平滑）。
3. 以 `exp(-cost/(2σ))` 加权平均控制序列，得到平滑的控制输出。
4. 执行第一步，滚动。

# 第四部分：方法论对比要点（学习总结）

| 维度 | 图搜索（A*/Dijkstra） | 采样（RRT/PRM） | 多项式/样条（后端） | MPC/TEB/MPPI |
| --- | --- | --- | --- | --- |
| 空间表示 | 栅格/图 | 连续/连续样本 | 连续轨迹 | 连续/滚动 |
| 完备性/最优性 | 完备且（启发式约束下）最优 | 概率完备，RRT*/PRM*渐近最优 | 达约束下的最优 | 局部滚动的最优 |
| 动力学处理 | 需扩展（Hybrid/Kinodynamic） | 需扩展（Kinodynamic RRT*） | 用时间调整 / 控制 input 限制 | 显式建模 |
| 避障 | 碰撞检测/代价地图 | 碰撞检测 | 凸包/走廊/距离场代价 | 软代价/硬约束 |
| 实时性 | 中等 | 快（非最优） | 快（梯度可解析） | 视求解器 |
| 主要风险 | 状态维数爆炸 | 窄通道、非最优 | 初值敏感、局部极小 | 计算成本、线性化误差 |

# 第五部分：学习建议路线

1. **少跑多读**：先用二维栅格跑 `Dijkstra → A* → JPS`，理解 `f=g+h` 与可采纳性。
2. **上采样**：跑 `RRT → RRT* → Informed RRT*`，理解概率完备 vs 渐近最优。
3. **会搜索判断**：掌握 `Theta*`（任意角）与 `Hybrid/Kinodynamic`（机器动力学）。
4. **后端平滑**：`Minimum Snap`（多项式 QP）→ `B-Spline + ESDF`（Fast-Planner）→ `TEB`（甜点：简单实时）。
5. **进阶**：`MINCO`（空间时间联合优化）、`MPC/MPPI`（重动力学与足式）。
